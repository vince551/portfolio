# Contributing

Thanks for helping improve Vince's portfolio.

## Good contributions

- UI/UX improvements
- Accessibility fixes
- Performance improvements
- Documentation corrections
- Responsive-design fixes
- Bug fixes that preserve the portfolio's identity

## Workflow

1. Fork the repository.
2. Create a focused branch.
3. Make and test your change.
4. Keep commits clear and focused.
5. Open a pull request describing what changed and why.

Please do not commit secrets, API keys, credentials, generated build artifacts, or private personal information.
